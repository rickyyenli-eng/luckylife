# AssetFlow · 個人資產管理與退休試算

免費、開源、不需註冊的個人資產管理工具。所有資料只存在使用者自己的瀏覽器。

## ✨ 功能
- **台股自動報價** — 輸入代號即可，支援上市/上櫃、個股與 ETF，一鍵更新全部持股
- **自訂資產類別** — 定存、儲蓄險、黃金、債券、基金、加密貨幣…每項可設定預估年報酬率
- **不動產與房貸試算** — 購入價、貸款金額、利率、年限、寬限期 → 自動算月付、剩餘本金、總利息、房產淨值
- **退休進度追蹤** — 依實際配置的加權報酬率與月投入，推算達標年數與屆時年齡
- **JSON 匯出匯入** — 跨裝置搬移、版本升級無痛
- **零後端** — 純靜態，可部署到任何地方

## 📁 專案結構
```
├── index.html      官網首頁（介紹頁）
├── app.html        工具主頁
├── css/main.css    樣式
└── js/
    ├── store.js    資料層與財務計算
    ├── quote.js    台股報價（Yahoo Finance + CORS proxy 備援）
    └── app.js      UI 渲染與互動
```

## 🚀 部署到 GitHub Pages
1. GitHub → New repository（Public）
2. Add file → Upload files → 把**所有檔案與資料夾**拖進去 → Commit
3. Settings → Pages → Branch 選 `main` / `(root)` → Save
4. 1-2 分鐘後開 `https://你的帳號.github.io/repo名/`

## 🔒 隱私
資料存於瀏覽器 localStorage，不上傳任何伺服器。清除瀏覽器資料會一併清除，請定期用「設定 → 匯出 JSON」備份。
